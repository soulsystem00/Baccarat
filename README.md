# Baccarat

넷마블 포커에서 바카라 하다가  
코인 다 떨어져서 플레이도 못하고  
무료로 주는 100 코인으로 플레이 하려니깐 답답해서  
그냥 내가 만들어 봄  
</br>
카드 애니메이션, 칩 애니메이션도 추가해서 그럴싸하게 만들어봤음  

## How to play

배팅 금액 설정하고  
어디에 배팅할지 결정하면  
배팅이 이뤄짐  
</br>
30초 후에 자동으로 카드 오픈함  
배팅 다 했으면 배팅 완료 버튼 눌러도 됨  

## Rules

카드는 첫째 자리 수만 사용함  
`A ~ 9`는 `1 ~ 9`에 대응하고  
`10, J, Q, K`는 `0`임  

`PLAYER`와 `BANKER`가 카드를 뽑아서 합이 더 높은 사람이 이김  
합도 첫째 자리 수만 이용함  
`ex) 9 + 9 = 18 => 8`  

세번째 카드 뽑는 규칙도 있는데  
이건 복잡하니깐 스킵  

둘 중 누가 이길지 맞추면 됨  


## Payout

| Bet Type    | Payout |
| ----------- | -----: |
| Player      |    1:1 |
| Banker      | 0.95:1 |
| Tie         |    8:1 |
| Player Pair |   11:1 |
| Banker Pair |   11:1 |
